# CareHub - Smart Healthcare Management Platform

## About the Project

CareHub is a healthcare management platform developed as a final year project. The aim of the project is to simplify interactions between doctors and patients by providing features such as appointment booking, prescription management, billing, and patient health monitoring.

The platform provides separate dashboards for doctors and patients. Patients can book appointments, view prescriptions, monitor their vitals, and track bills, while doctors can manage appointments, monitor patient health data, and issue prescriptions.

---

## Features

### Patient Features

* Sign up and login
* Book appointments with doctors
* View appointment details
* Monitor health vitals
* View prescriptions
* Check billing information

### Doctor Features

* Sign up and login
* Manage appointment slots
* View patient information
* Monitor patient vitals
* Add prescriptions
* Complete appointments and generate bills

### Vitals Monitoring

* Simulated real-time health vitals
* Heart rate monitoring
* Oxygen level monitoring
* Temperature monitoring
* Graphical representation of patient vitals using charts

---

## Project Workflow

1. Patients register and log in to the system.
2. Patients book appointments with available doctors.
3. Doctors manage their available slots and view appointments.
4. Doctors can add prescriptions after consultation.
5. Bills are generated for completed appointments.
6. Patient vitals are monitored and displayed using cloud-based data from ThingSpeak.
